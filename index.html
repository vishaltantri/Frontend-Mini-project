About me

Frontend, learned by building.

I am Vishal C Tantri, a third-year M.Tech (Integrated) Computer Science and Engineering student at Vellore Institute of Technology. I enjoy the part of software where structure meets craft: turning a plain requirement into a page that is easy to read, quick to scan and comfortable on any screen size.

This mini project collects every exercise from the Frontend Design lab into a single, coherent product. Instead of thirty disconnected files, each technique becomes a real campus feature — the travel club publishes a bucket list, the hospital runs its header and registration desk, the store handles checkout, and the esports club hosts a gaming banner. The shared design system keeps them consistent, while the pages marked as specified deliberately stay in plain HTML or inline CSS to show the underlying skill.

Everything is static: no database, no server, no build step. Open index.html or drop the folder on any static host and it runs.
