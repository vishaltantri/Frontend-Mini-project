This page shows the four structural blocks of a classic web layout — header, left menu, content and footer — using only HTML div elements and no CSS at all. Because no styling is applied, the browser stacks each block in the order it appears in the document.

The same markup would gain columns and spacing as soon as a stylesheet is added; the exercise is about the structure underneath.
